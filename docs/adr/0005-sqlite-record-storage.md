# SQLite 记录存储与独立新目录

2026-10-17，用户要求将记录主存储从分段 JSONL 改为内嵌 SQLite，并明确放弃历史、不做迁移。此决定替代 ADR-0001 的记录格式选择及迁移安排，但不改变 ADR-0004 的官方 HTTP 执行采集契约。已有对象/时间/模型筛选、分页和详情需求使用数据库索引；不再由应用维护分段扫描与页内文件位置。配置、身份种子和固定诊断仍保留原有职责，不为格式替换重写采集规则或管理 API。

使用单连接、PERSIST 回滚日志、FULL 同步、禁用缓存溢写和增量 auto-vacuum。工作日志实际分配并计入整目录预算，随主库逐步增长，降预算时保留既有空间供过期删除与物理回收复用，避免维护需要重新申请整库日志空间。代价是保守工作空间约占总预算的一半，主库还包含索引；1 GiB 不是净正文容量。不上 WAL，是为了避免在现有串行访问模型中增加 checkpoint 和日志增长管理；不使用需要全库副本的定期 VACUUM。

安装切换至全新空 state-dir，旧 JSONL、监控配置、名称和设置均不导入，旧目录原样保留。新存储身份标识与 schema 明确拒绝新旧目录混用；升级后重新发现并选择对象，回滚须同时恢复旧插件、旧配置和旧目录。本次执行和验收按用户后续授权仅在 Linux 进行，本机只编辑源码，不把历史 macOS 报告作为此版本通过证据。
