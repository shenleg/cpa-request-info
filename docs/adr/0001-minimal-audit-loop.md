# 固定宿主与最小审计存储

2026-10-14，按已批准实施方案：固定官方 CLIProxyAPI `v8.0.27` commit `bf9341629ef2300ac9d846a2e80fe2756f63a671`，通过最小增量补丁在鉴权后、协议改写和模型路由前提供只读观察，再由 Go/CGO C ABI 插件提取正文。执行拦截器可能漏掉路由前失败且允许改写，不适合作为本模块的入站合同。

宿主统一以持久随机 seed 和域分隔 HMAC-SHA-256 派生无秘密审计对象 ID。相比裸 Key 摘要，它避免只凭管理输出猜测低熵 Key；相比按下标或名称关联，它在重排和重新加入时保持稳定。seed 丢失后不能静默初始化另一套身份；seed 不是登录凭据，但其文件和备份仍须保护。

01 采用标准库有界分段 JSONL，而不是提前引入 SQLite 驱动、索引和 WAL 预算。这样能从第一条记录起按实际编码输出及辅助文件核算空间，代价是后续查询性能、清理和故障恢复仍需完善。本票不承诺吞吐或完整第一版验收，后续若改存储格式需明确迁移，不得静默删除历史。
