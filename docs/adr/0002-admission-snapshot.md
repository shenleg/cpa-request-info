# 接收快照与独立主动暂停

2026-10-14，ticket 02 将独立观察契约升级为 v2（ABI 1、RPC schema 6 不变）：在可信内置客户端鉴权后、读体前同步取得固定小采集决策，并随请求绑定原观察者与非持久化采集器代际；读体后不得再查当前名单、主动暂停或 Key 目录来改写本次资格。相比读体后采样或保存全局提交ID→历史配置表，这能让慢体、暂停/恢复及未来每次 WebSocket 提交采用一致语义，同时不增加无界待提交状态或凭据副本；代价是一次不等落盘的同步准备调用，旧契约必须明确不兼容而不能降级。准备与投递桥接失败发生在采集器之前，由宿主保留无秘密的有界运行期计数并投影到管理缺口，不能仅写日志或把失败解释成正常跳过；不承诺该运行期计数跨异常重启恢复。

持久对象目录将当前名称、是否受监控与全局主动暂停分开，停用对象仍计入1024个配置上限；输入记录只持有稳定身份，不保存名称快照。主动暂停是预期跳过，不改变 writer 的存储故障状态，因此不会追溯取消已接收副本或被故障自动恢复解除；旧 `map[id]name` 在加载时兼容、下次成功配置提交才升级，损坏或未知格式不得被更新覆盖。保留期、异常恢复及完整查询仍由后续票完善。
