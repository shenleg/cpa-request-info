## 发现及修正

1. 前端编辑期间内联脚本变化导致 CSP 摘要校验失败；同步摘要后定向校验与真实页面通过。未放开 unsafe-inline。
2. 旧系统测试的持久化/详情白名单未包含新字段，导致多项用例失败；只将 `request_reasoning` 加入明确白名单，保留其他隐私断言，完整回归通过。
3. 真实浏览器在翻页后将筛选按钮滚到 iframe 顶部，被宿主浮动“刷新全部”按钮截获，页面重载使临时鉴权丢失。用父页面命中元素确认后，为嵌入页增加滚动避让，定向及两端全套通过。
4. 选区复制后的焦点恢复发生在按钮被 busy 禁用期间；改为操作解锁后恢复焦点，实际复制与键盘回归通过。
5. 远端写入最初被权限检查拒绝；用户明确授权主会话直接执行后，在新测试目录验收，未绕过限制或修改生产环境。
6. 两轴审查共同发现合法 int64 预算超过 `Number.MAX_SAFE_INTEGER` 后被 `response.json()` 舍入，页面不再显示原值。改用原响应文本与 JSON reviver 的 `context.source` 保留原十进制数字，后端 numeric int64 契约不变；新增原始 JSON number `9007199254740993`、MaxInt64 的列表和详情断言。两端真实浏览器回归通过，已查看仅含 MaxInt64 标签的有限截图。
