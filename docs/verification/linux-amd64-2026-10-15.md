## 准备与执行

经授权安装 C 编译器、Chromium 运行库和中文字体，并创建普通测试用户。Go、Node 与浏览器安装于专用目录或该用户缓存；Go/Node 官方归档通过 SHA-256 校验。依赖按仓库锁文件安装，不执行下载的安装脚本。

默认 `proxy.golang.org` 连接超时后，本轮使用 `GOPROXY=https://goproxy.cn,direct`，未关闭校验和验证。首次 GitHub 克隆超时后，以仅对构建进程生效的 `http.version=HTTP/1.1` 重试成功。Chromium 首次下载 TLS 断开，安装器重试后成功；这些失败均属于依赖准备，不是测试通过记录。
