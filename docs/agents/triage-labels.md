# Triage 标签

本文件将工程技能使用的五种标准 triage 角色映射到本仓库的标签字符串。

| 标准角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求完整，可交由 agent 处理 |
| `ready-for-human` | `ready-for-human` | 需要由人来实现 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到某个角色时（例如“添加可由 agent 处理的 triage 标签”），使用表格中对应的标签字符串。

如果本仓库之后采用其他标签名称，请更新表格右侧一列。
