# 实测原版 CPA 的官方插件输入记录能力

Status: completed

## 目标

用独立 C ABI 探针和真实官方宿主验证接口，不正式改造已有审计插件。

## 验收

- [x] 精确官方源码导出，独立构建，不混入宿主补丁。
- [x] 三协议 HTTP、SSE、身份与提交/执行标识，失败覆盖。
- [x] 重试/账号切换、嵌套执行、同文重交。
- [x] 普通及 Codex duplex WebSocket 的 create/append/steer。
- [x] 管理鉴权、静态资源、有界摘要与隐私检查。
- [x] macOS 与隔离 Linux 同源码、同实例各两轮。
- [x] 中文结果、有限证据、改造建议；测试进程正常退出，文件保留。
