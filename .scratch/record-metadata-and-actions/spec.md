# 执行记录的思考设置、模型下拉与纯文本复制

Status: completed

## 目标

在官方 HTTP 执行记录中保存 Before 可见的思考声明，将执行输入模型筛选改为已保存模型的下拉选项，并在单条详情提供复制已保存纯文本的按钮。

## 行为

- 新记录带 `request_reasoning` 对象，仅允许 `effort`、`type`、`budget_tokens`。Chat 读取 `reasoning_effort`，Responses 读取 `reasoning.effort`，Messages 读取 `output_config.effort`、`thinking.type` 和 `thinking.budget_tokens`。空对象表示未指定；旧记录缺字段表示未记录，不改写历史。
- 等级与模式分别最多64、32 UTF-8字节，必须为非空字符串；预算为非负 int64，显式0和缺失不同。不保存其他配置或完整对象，不按预算推算等级，不从模型名或宿主配置猜最终值。畸形声明报告固定提取缺口，不影响模型请求。
- 列表与详情展示请求值，不承诺后缀、协议转换或 CPA 配置覆盖后的最终上游强度。新版本可读取旧记录；旧二进制严格拒绝新字段，写入后不能用同一 state-dir 直接降级。
- `GET /models` 受现有管理鉴权保护，返回全部已同步且未到期历史的非空模型名，去重排序。不受其他筛选和分页限制，不来自配置或上游目录。模型筛选继续原字符串精确匹配，空值表示全部。
- 详情按钮只复制成功加载的已保存 `text`，保留换行和空白，不加元数据、不复制预览或未保存尾部。未加载成功或鉴权撤销时禁用。支持安全上下文 Clipboard API，并为缺接口的普通 HTTP 页面提供选区复制；权限拒绝或复制失败明确提示手动操作，不误报成功。

## 非目标

不修改 CPA 宿主、客户客户端、模型请求或回复，不保存完整请求，不增加思考强度筛选，不迁移历史，不部署生产，不自动提交或推送。
