输入审计

当前支持 Chat Completions、Responses HTTP、Responses WebSocket 与 Anthropic Messages：仅审查本次末尾新用户消息；WebSocket 按每次客户端模型提交独立记录，不记录握手或控制消息；Responses 字符串 input 直接作为本次用户文本；Anthropic 仅含 tool_result 的末尾 user 正常跳过，混合消息只保留新内容，不提取工具结果内部数据。图片/音频/视频/文件只保存固定占位符，不保存附件载荷或工具内容，不回查 previous_response_id 或会话历史。未知块会产生提取不完整标记与缺口诊断；普通文本中的链接、Base64 和秘密不自动脱敏。正文按配置保存 1–65536 字节内的 UTF-8 前缀；配置变更只影响后续提交，无须重连。应用层不加密，尚不支持七天自动过期清理和完整故障恢复；仅供隔离合成数据验收，不适用于生产审计。
