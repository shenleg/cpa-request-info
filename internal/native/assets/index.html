输入审计

当前支持 Chat Completions、Responses HTTP、Responses WebSocket 与 Anthropic Messages：仅审查本次末尾新用户消息；WebSocket 按每次客户端模型提交独立记录，不记录握手或控制消息；Responses 字符串 input 直接作为本次用户文本；Anthropic 仅含 tool_result 的末尾 user 正常跳过，混合消息只保留新内容，不提取工具结果内部数据。图片/音频/视频/文件只保存固定占位符，不保存附件载荷或工具内容，不回查 previous_response_id 或会话历史。未知块会产生提取不完整标记与缺口诊断；普通文本中的链接、Base64 和秘密不自动脱敏。正文按配置保存 1–65536 字节内的 UTF-8 前缀；单条上限变更只影响后续提交，无须重连。常规可处理审计故障采用 fail-open，不拒绝或修改模型调用，但同步输入观察仍有处理耗时。native 与宿主同进程，进程级崩溃不隔离；异常重启只报告真实不确定性，重启诊断不等于完整故障恢复，不保证零丢失或 exactly-once。应用层不加密；仅供隔离合成数据验收，不适用于生产审计。

总预算、保留期限与单条正文上限

合法范围为 4–1024 MiB，默认 1024 MiB；允许能精确换算为整数字节的小数。预算包含正文、配置、诊断、未知辅助文件和维护临时空间，预留不是额外额度。保存后的预算优先于 YAML 初始默认值；降低预算不删除未过期历史，已有占用超过新预算时停止新采集。正常满额可使用配置预留；主动降额超预算后，部分管理写入可能被拒绝，需调高到足够预算。预算不保证任意流量都能保存七天。

合法范围为 1–30 天，默认 7 天，从服务端接收提交起算；暂停、移除监控和停机不冻结期限。到期立即退出查询，后台每分钟清理。调长保留期不延长已有历史；缩短会使现有历史提前到期，保存前必须确认。

合法范围为 1–65536 字节；仅改变后续提交，已接收副本保留原上限，旧正文不重新截断，不改变模型收到的完整输入。

三项设置一起保存；取消缩短确认时三项都不提交。逻辑到期和空间回收不等于磁盘、数据库空闲页、快照或备份的安全擦除；应用层不加密。
