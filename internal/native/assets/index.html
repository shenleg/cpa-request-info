合法范围为 1–30 天，默认 7 天，从 Before 回调所见时刻起算；暂停、移除监控和停机不冻结期限。到期立即退出查询，后台每分钟清理。调长保留期不延长已有历史；缩短会使现有历史提前到期，保存前必须确认。

支持范围与使用说明
当前仅记录官方 Before 回调所见的 Chat Completions、Responses HTTP 与 Anthropic Messages 执行输入；不包括路由前失败或插件模型回调；WebSocket 不支持，普通与 duplex WebSocket 均不采集。不等于完整客户端输入审计：时间是 Before 所见时刻，模型可能已被宿主改写；同一客户端提交可对应多次执行记录，不按 TraceID 合并。先用目标 Key 发送受支持的 HTTP 请求，再在监控对象中刷新发现并选择；默认不监控。明确的辅助、压缩和子任务调用不保存正文，但仍可发现匿名对象；其余仅提取执行正文末尾用户消息的允许内容，不回找旧用户发言。用途标签来自请求头，main/turn不是人工原文认证；无用途标记继续原提取，旧记录显示未记录用途。执行正文可能已经包含宿主补回的上下文。Responses 字符串 input 直接作为用户文本；Anthropic 仅含 tool_result 的末尾 user 跳过，混合消息不提取工具结果内部数据。图片/音频/视频/文件只保存固定占位符，不保存附件载荷或工具内容，不回查 previous_response_id 或会话历史。未知块会产生提取不完整标记与缺口诊断；普通文本中的链接、Base64 和秘密不自动脱敏。正文按配置保存 1–65536 字节内的 UTF-8 前缀；单条上限只影响后续回调。常规故障采用 fail-open，不拒绝、终止或修改模型调用，但同步提取仍有耗时。未收到回调的数量未知，不能从记录数推算。native 与宿主同进程，进程级崩溃不隔离；异常重启只报告真实不确定性，不保证零丢失或 exactly-once。应用层不加密；仅供隔离合成数据验收，不适用于生产审计。
